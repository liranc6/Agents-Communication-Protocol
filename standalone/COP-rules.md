# COP (machine-only; full ref = COP.md, also COP, NOT loaded; edit both together)
Principle: compression scales w/ shared context; cost unit = tokens. Unlisted case -> judge by: does reader share this file+glossary?
T0 human-read (chat commit PR report user-handoff log review code comments data cfg memory-metadata): normal prose, zero COP codes/symbols — UNLESS user explicitly asks for radio/terse replies ("like radio comm," "skip grammar if implied," "use symbols to save tokens"); then chat replies to that user may go telegraphic + use ops/symbols too, until told otherwise. Still never forward raw peer (T1/T2) shorthand verbatim — rewrite for the user even in terse mode.
T3 agent-only docs (INSIGHTS, specs, runbooks, task/handoff/state files; only agents read+write): dense COP, not T0 prose; file-local Legend at top; one writer per shared file, others send it entries. Any human reads/maintains it, or unsure who reads it -> T0.
T1 my thinking, scratch/tmp, memory body: max dense. Think in COP: in the reasoning/notes/plans you control (visible thinking, scratch, own plans), write fragments from first token (obs|inf|?, `x -> y`), NOT full-sentence draft then compress. Plan shown to a human = T0. Only text a human reads gets rewritten as prose.
T2 any agent<->agent msg (subagent, workflow agent, teammate, other session): dense. Peer starts cold -> state explicitly: goal+why, constraints, paths, done-criteria, known facts (so peer skips rediscovery). Hook adds PEER; set N; define glossary terms used inline (peer never reads glossary files). Never make peer read COP/glossary files. Need raw content -> ask for it explicitly.
PEER = the peer.txt block; where host supports hooks, hook auto-appends it to subagent prompts lacking "COP:" (default N=15); else paste it into every peer prompt. Still state N yourself when different. Unhooked spawn paths (workflow agent() etc) -> paste manually.
Input: probe first (wc -l) -> read ranges (offset/limit); whole file only if <=200 lines or truly needed. Filter at source; noisy build/test `| tail -20`. No re-read unchanged, no re-run seen. Wide sweep (many files/dirs) -> subagent summary, not raw dump. Tool inputs = output tokens: relative paths from cwd, no repeated long abs paths, batch probes in 1 call, no decorative echo separators.
Process: T1/T2 cite tool output, don't paraphrase it back (human reply: state the finding in prose). Decide once: no re-deriving established facts, no re-litigating settled choices, no narrating options I won't take. Long task -> F1..Fn one-line fact ledger in scratch, cite by id (survives compaction).
Write (T1/T2): telegraphic. Drop grammar when meaning inferable: articles, copulas, aux verbs, pronouns, filler connectives, full sentences -> fragments, lists, `x -> y`. Drop hedges pleasantries restating. Keep every reasoning step + logic words (NOT if unless only all none because before after): they carry meaning, not grammar. Common words whole (1 token); abbreviate only long ids/multi-word phrases; no ad-hoc slash/unicode shorthand (extra tokens; listed codes and tags are fine). Exact: numbers paths ids cmds quotes errors thresholds. Negation NOT. Pointer>copy (path:line sha run-id url). Delta vs last known state only (reader with prior state; cold reader gets full state). Tag obs|inf|?; inf->obs only after check. Cold reader could parse 2 ways -> spell out. Before irreversible/outward act (delete push send deploy publish) -> state intent in plain full words, then get confirmation unless user already authorised that act. T1/T2 feeding T0 -> rewrite as prose; never forward peer shorthand to user.
Codes: ACK; WIP; DONE; BLOCK(reason); Q? question; FYI; NI need info; ND need decision; CFM confirm; PTAL review req; ETA; SITREP summary; TP/TF test pass/fail; VRF verified; UNV unverified. Ops: -> then/input to; => yields; @ at; ! urgent; + add; - remove; ^ update/push; ~ approx; != differs; $ budget/limit.
Line: STATUS|target|result|evidence|next  ex: DONE|runner.py:120 retry fix|TP 14/14|obs|next PR
Gloss: <project root>/.cop/shorthand.md `T=exp`; link it from project agent-instructions file (CLAUDE.local.md `@.cop/shorthand.md`, AGENTS.md, ...); create both on first add. Add if >=3 uses in session, expansion >=3 tokens, unambiguous in project. Cap 30; prune unused. No ad-hoc abbrev outside COP/glossary.
Densify existing docs: no separate "extra efficient" mode; follow ref "Densify existing text" (find repeats w/ script first, file-local Legend, never abbrev literals/ids/proper nouns).
Measure (Claude Code only; savings unproven until measured): python3 cop_stats.py --main [--split "YYYY-MM-DD HH:MM" UTC]. Rule not paying its load -> cut.
